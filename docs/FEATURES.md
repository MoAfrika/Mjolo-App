# Feature status

Status describes the supplied source and local-service implementation, not a hosted production deployment. Production Supabase, SMTP, Netlify and the requested administrator are not connected or provisioned without the operator's credentials.

| Area                              | Implementation                                                                                                                                   | Validation / limit                                                                                                                                                                                                               |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Brand and navigation              | Responsive porcelain/plum/berry interface; Discover / Likes / Chats / Plans / You; light/dark; reduced motion; keyboard controls                 | Browser screenshots and automated accessibility checks recorded in VALIDATION.md. Editorial stock photography is not bundled; member photos are real private uploads. QA screenshot images are clearly fictional local fixtures. |
| Registration and adult onboarding | Supabase Auth, unique username, server-side DOB/consent, adult-only eligibility                                                                  | Real local provider registration and delivered verification email tested. DOB declaration is not documentary age assurance.                                                                                                      |
| Verification and recovery         | Provider email verification, resend, real reset email and provider password update                                                               | Local mail delivery, confirmation and password recovery tested. Production SMTP requires configuration. Badge says email confirmed only.                                                                                         |
| Sessions and password security    | Supabase PKCE sessions, refresh rotation, SQL session-existence checks, suspension and logout                                                    | New sessions, revocation and correctly signed expired tokens tested. Browser tokens use provider-managed browser storage, not HttpOnly cookies.                                                                                  |
| Profiles and preferences          | Editable introduction, interests, languages, intentions, gender preferences, province/city/broad area, age bounds, budgets, availability         | Database persisted; birth date fixed once provided. Location is manual; no GPS or home-location fields.                                                                                                                          |
| Media                             | Authenticated JPEG/PNG upload function, raster validation, compression, metadata removal, private bucket, authenticated reads, six-photo limit   | Real local storage upload/download; anon denial, client upload denial, recipient-preference denial and blocked-user denial tested. No automated content classifier.                                                              |
| Discovery                         | Server-enforced adult/completeness/verification/status eligibility and age, gender, intentions, province/city/area filters                       | Actual SQL queries and negative filter cases tested. No fabricated fallback profiles.                                                                                                                                            |
| Likes and matching                | Sent likes; reciprocal matching under transaction lock, unique canonical pair                                                                    | One-sided denial and concurrent duplicate reciprocal requests tested. No random matches or paid incoming-like unlocks.                                                                                                           |
| Same Page                         | Explains shared intentions, interests, availability and overlapping budgets                                                                      | Fact-based utility tests. No invented compatibility score or AI claims.                                                                                                                                                          |
| A Proper Introduction             | Conversation starter from a match's voluntarily shared interests                                                                                 | Available in authorised match chat; no automatic sending.                                                                                                                                                                        |
| Messaging                         | Persistent text, match-only RLS, authorised Postgres Realtime, idempotent retries, rate limiting, pagination                                     | Real Realtime delivery and cross-account denial tested. No E2E encryption, attachments or read receipts.                                                                                                                         |
| Date Within Reach                 | Public venue/broad area, SAST times, total ZAR budget, propose/accept/amend/cancel, stale-write detection                                        | Proposal, recipient-only acceptance, amendment/reacceptance and stale-write denial tested. Payments and venue reservations are not implied.                                                                                      |
| Date Check-In                     | User-initiated system sharing/copy, calendar download with optional one-hour reminder                                                            | Requires the user to share/import. No emergency monitoring, push/SMS integration or automatic trusted-contact messaging.                                                                                                         |
| Your Pace                         | Pause discovery, hide city/area, low-data uploads, calendar reminder preference, quiet-hour preferences                                          | Stored settings; pause and privacy obey SQL. Quiet hours are reserved for future notification delivery; no connected push service.                                                                                               |
| Safety                            | Block/unblock, report queue, moderator suspension/restoration, audit log                                                                         | Blocking revokes interaction/media; unblocking does not restore deleted match history. Backend role escalation denied.                                                                                                           |
| Administrator                     | Controlled server-only, single-use provisioning invitation; reserved identity; verification and mandatory initial password change; report review | Provisioner and positive/negative moderation checks exercised on a disposable local account. Hosted administrator not created. MFA is a launch-review requirement, not implemented.                                              |
| Privacy                           | Profile controls, own-data JSON export, password-confirmed account/media deletion, public implementation notice                                  | Export and real provider deletion tested. Operator legal identity, POPIA review, retention/backup policies and privacy contact remain required.                                                                                  |
| Localisation                      | en-ZA, Johannesburg timezone, ZAR, inclusive stored language preferences; central initial copy map                                               | Full translated catalogs and a UI-language selector are deferred. No machine translation is claimed.                                                                                                                             |
| Offline/error handling            | Offline banner, unsent chat text retained while reconnecting, explicit retry/errors, empty/loading/success states                                | Requests never silently create demo results. Full offline caching or offline writes are not implemented.                                                                                                                         |
| Deployment                        | Netlify configuration, typed function, security headers/CSP, Supabase migrations and setup guide                                                 | Build validated locally. Hosted smoke test, production SMTP and operator-approved deployment outstanding.                                                                                                                        |
| Optional features                 | AI, payments, video, events                                                                                                                      | Deferred; no simulated integrations.                                                                                                                                                                                             |
